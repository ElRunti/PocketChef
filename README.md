# Pocket Chef

Pocket Chef es una app mobile-first hecha con React y JavaScript.

## Tecnologias

- React
- JavaScript
- Vite
- CSS
- Lucide React

## Comandos

```bash
npm install
npm run dev
npm run build
npm run lint
```

## Estructura

```txt
src/
  features/
    home/
      HomePage.jsx
      components/
    recipes/
      data/
  shared/
    components/
    styles/
```

## Seguridad

El archivo `.gitignore` evita subir dependencias, builds, archivos temporales,
variables de entorno y archivos comunes de credenciales.
